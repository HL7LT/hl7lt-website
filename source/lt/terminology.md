# Terminologija

**HL7 Lietuvos terminologijos registras** suteikia prieigą prie kodų sistemų,
reikšmių rinkinių ir susiejimų, palaikančių visus Lietuvos FHIR diegimo vadovus.
Šie terminologijos ištekliai užtikrina **semantinį nuoseklumą** ir **sąveikumą**
tarp sveikatos priežiūros sistemų.

- ![](/.gitbook/assets/termservice.png)
  ### Terminology Services
  API pagrindu veikianti prieiga prie Lietuvos FHIR terminologijos išteklių ir validavimo įrankių.
  [Terminology eXplorer](https://tx.hl7.lt){.button}
- ![](/.gitbook/assets/codesystem.png)
  ### Code Systems
  Nacionalinės ir srities kodų sistemos, naudojamos Lietuvos FHIR profiliuose.
  [Peržiūrėti saugyklą](https://tx.hl7.lt/fhir/CodeSystem/){.button}
- ![](/.gitbook/assets/valueset.png)
  ### Value Sets
  Standartizuoti kodų rinkiniai, atspindintys klinikines ir administracines sąvokas.
  [Peržiūrėti saugyklą](https://tx.hl7.lt/fhir/ValueSet){.button}
- ![](/.gitbook/assets/conceptmap.png)
  ### Concept Maps
  Susiejimai tarp Lietuvos ir tarptautinių terminologijų, tokių kaip SNOMED CT, LOINC ir ICD-10.
  [Peržiūrėti saugyklą](https://tx.hl7.lt/fhir/ConceptMap){.button}
